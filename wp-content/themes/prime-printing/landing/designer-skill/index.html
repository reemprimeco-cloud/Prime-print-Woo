What it does

وش يسوي المصمم؟

يفكر بالطباعة قبل الشكل. كل فكرة يقترحها تنطبع وتنقص وتتشطّب بدون مفاجآت عند المطبعة.

01

ثلاث أفكار مختلفة

كلاسيكي رسمي، وجريء، وفاخر بتشطيبات. كل فكرة بألوانها وخطوطها وتوزيعها.

02

مواصفات طباعة جاهزة

ألوان CMYK، ودقة 300 DPI، وبليد 3 mm، وهوامش أمان، والملف المطلوب للمطبعة.

03

تغليف ودايلاين

نوع البوكس والخامة وسماكة الكرتون، وطبقات القص والتكسير، والفويل والسبوت يو في والبصمة.

04

برومبت صور لكل فكرة

برومبت مفصّل تحطه في Gemini أو ChatGPT أو Midjourney وتطلع لك صورة موك أب.

05

ملاحظات إنتاج

ينبهك للأخطاء قبل لا تصير: كثافة الحبر، الخطوط الصغيرة، والنص العربي المتكسّر.

06

يسأل قبل لا يفترض

ما يخمّن المقاسات. إذا ناقصه شي يطلبه منك بقائمة وحدة قصيرة ويكمل.

Install

طريقة التثبيت خطوة بخطوة

الخطوات على claude.ai وتطبيق Claude على الكمبيوتر. من الجوال تقدر تستخدمه بعد التثبيت، بس التثبيت نفسه أسهل من الكمبيوتر.

METHOD 01

تثبيته كبروجكت

الأنسب إذا تبي تحفظ هوية براندك معه.

prime-designer-project.md
  1. حمّل ملف البروجكت

    من الزر اللي فوق. افتحه بأي برنامج نصوص (Notes أو Notepad).

  2. سوِّ بروجكت جديد

    من القائمة الجانبية في Claude اختار Projects ثم + New project. سمّه مثلاً «مصمم برايم».

  3. الصق التعليمات

    داخل البروجكت اضغط على Instructions (تعليمات البروجكت)، والصق محتوى الملف كامل، وبعدين Save.

  4. أضف هويتك (اختياري)

    من قسم Files ارفع شعارك، ودليل الهوية، والألوان والخطوط. المصمم بيرجع لها بكل تصميم.

  5. ابدأ

    أي محادثة جديدة داخل البروجكت، المصمم جاهز فيها.

METHOD 02

تثبيته كمهارة

يصير المصمم حاضر بكل محادثاتك، وClaude يستدعيه بروحه.

prime-designer.zip
  1. حمّل ملف المهارة

    نزّل prime-designer.zip ولا تفك الضغط. Claude يبيه ZIP زي ما هو.

  2. فعّل تشغيل الكود

    من Settings → Capabilities فعّل خيار Code execution and file creation. المهارات ما تشتغل بدونه.

  3. ارفع المهارة

    روح Customize → Skills، اضغط + ثم Create skill ثم Upload a skill، واختار الملف.

  4. تأكد إنها مفعّلة

    بتطلع prime-designer في قائمة مهاراتك. تأكد إن المفتاح جنبها شغّال.

  5. اطلب تصميمك

    بأي محادثة اكتب طلبك عادي. إذا تبي تضمن إنها تشتغل، قل: «استخدم مهارة prime-designer».

BONUS · CLAUDE CODE

للمطورين: Claude Code

إذا تستخدم Claude Code في التيرمنال.

إذا رفعت المهارة على حسابك في Claude (الطريقة 02)، بتشتغل في Claude Code تلقائياً لما تسجّل دخول بنفس الحساب. أو ثبّتها يدوياً على جهازك:

mkdir -p ~/.claude/skills unzip prime-designer.zip -d ~/.claude/skills/

بعد التثبيت سكّر Claude Code وافتحه من جديد. المهارة بتكون في ~/.claude/skills/prime-designer/SKILL.md

صمم لي بوكس فاخر لعطر بمقاس داخلي 8×8×14 سم، أبيه مغناطيس، مع فويل ذهبي واقتراح الخامة.

ستيكر دائري 6 سم لمنتج عسل، أبي ثلاث أفكار وملاحظات الطباعة على ورق شفاف.

نصيحة من المطبعة: مولّدات الصور غالباً تكتب العربي غلط. خذ الصورة كفكرة وموك أب، وحط النص الحقيقي بعدين في Illustrator أو Canva قبل لا ترسل الملف للطباعة.

أسئلة سريعة

هل المهارة مجانية؟

إيه، مجانية بالكامل. حمّلها واستخدمها لشغلك أو لعملائك.

ما لقيت قسم Skills في الإعدادات

تأكد إنك فعّلت Code execution and file creation من Settings → Capabilities، وحدّث الصفحة. إذا ما زال ما يطلع، استخدم طريقة البروجكت، تعطيك نفس النتيجة.

الرفع يطلع خطأ

لا تفك ضغط الملف ولا تعيد ضغطه. ارفع prime-designer.zip زي ما نزل.

أقدر أثبّت الاثنين؟

إيه. المهارة تشتغل بكل مكان، والبروجكت تخليه لبراند معيّن مع ملفات هويته.
